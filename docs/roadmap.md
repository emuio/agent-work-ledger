# Roadmap

## v0.1: Protocol and Org Projection

- Define event and state schemas.
- Provide agent-facing skills for work logging, org-agenda projection, and human checkpoints.
- Render `events.jsonl` into an org-agenda compatible file.
- Include Codex, Claude Code, org-mode, and GitLab examples.

## v0.2: Dashboard and Reports

- Improve static HTML dashboard output.
- Improve Markdown daily report output.
- Add projection tests and fixture-based examples.
- Document common team workflows.

## v0.3: Integrations

- Add GitHub and GitLab comment projection examples.
- Add Feishu and WeCom card projection examples.
- Explore MCP server support for appending and querying ledger events.

## v0.4: Multi-Agent Coordination

- Support agent ownership and handoff fields.
- Track dependencies between tasks.
- Add checkpoint delegation workflows.
- Add conflict handling for concurrent agents.

## v1.0: Stable Protocol

- Freeze core event semantics.
- Publish compatibility guarantees.
- Provide enterprise audit guidance.
- Maintain migration notes between schema versions.
